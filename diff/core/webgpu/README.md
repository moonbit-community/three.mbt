# WebGPU / TSL shader harness and the mock GPU (diff/core/webgpu)

Upstream comes from `THREE_UPSTREAM` (default `.repos/three.js`, see tools/fetch_upstream.sh);
`--repo <checkout>` on the runners points the MoonBit side at another checkout of the port
(default: this repository). Run everything from this directory.

Expected: `node shader_diff/run.mjs` -> `1846 identical, 0 different or missing` (about 20 s
with warm `_build`; it runs about 30 `moon test` invocations with `SHADER_DIFF=1`). It is
check `shader` of `node diff/run_all.mjs`.


shader_diff/   Generated shader text, byte for byte.
  node shader_diff/run.mjs [name ...]
  - MoonBit side: src/nodes/shader_diff_test.mbt, run with SHADER_DIFF=1; each scenario
    prints `@@SHADER <name> <json>` ({ code, result, vars, uniforms }).
  - Upstream side: shader_diff/upstream.mjs, same scenario names, same record format.
    Renderer: `new WebGPURenderer( { canvas: stub } )` with `renderer._bindings = undefined`
    (mirrored by `Renderer::foundation_stub()`); builder: base `NodeBuilder( null, renderer )`
    in the fragment stage, `flowStagesNode( node )`.
  - Whole materials: once WGSLNodeBuilder / GLSLNodeBuilder are ported, build
    `new WGSLNodeBuilder( mesh, renderer )` with scene, camera, material and
    `lightsNode = renderer.lighting.getNode( scene, camera )`, call `build()` and compare
    `vertexShader` / `fragmentShader` (upstream/probe_wgsl.mjs shows it works in Node; that is how G8/G10 do it now).
  - G4 (display, gpgpu, parsers): src/nodes/g4_shader_diff_test.mbt and
    shader_diff/upstream_g4.mjs (scenarios `g4_`, run by run.mjs with the others);
    `node shader_diff/run_g4.mjs [--show] [name ...]` runs only these. Both sides use
    `G4Builder` (a NodeBuilder with a GLSLNodeParser and GLSLNodeBuilder's
    `buildFunctionCode`, so layout functions and their `fn<id>` names appear in the
    record's `codes`). Records add `codes` and `extra`.
  - G8 (WGSLNodeBuilder): src/renderers/webgpu/g8_shader_diff_test.mbt and
    shader_diff/upstream_g8.mjs (scenarios `g8_`); run.mjs also runs the
    `*_shader_diff_test.mbt` files of src/renderers/webgpu in their own `moon test`.
    `node shader_diff/run_g8.mjs [--repo <checkout>] [--show] [name ...]` runs only these.
    Both sides use the real WGSL builder on an initialized-looking renderer (fake device
    features / compatibility mode); records are flow + `decl` (the builder's
    declarations) + `bindings`, whole compute shaders (`build()`), and whole materials
    through a stand-in for `NodeMaterial.build` (vertex/fragment stacks, then
    `buildCode()`).
  - G10 (GLSLNodeBuilder): src/renderers/webgl_fallback/g10_shader_diff_test.mbt and
    shader_diff/upstream_g10.mjs (scenarios `g10_`); run.mjs also runs the
    `*_shader_diff_test.mbt` files of src/renderers/webgl_fallback. `node
    shader_diff/run_g10.mjs [--show] [name ...]` runs only these. Both sides build with the
    real GLSL builder on `WebGPURenderer( { forceWebGL: true } )` whose WebGLBackend has the
    diff/core/webgl mock (harness/mock_gl.cjs) as `gl` and a real `WebGLExtensions` over it (renderers a: default
    mock extensions, b: none, c: + WEBGL_clip_cull_distance, d: keyword diagnostics). G8's
    scenarios re-run through GLSL (minus 12 WGSL-only ones upstream throws on), then GLSL
    specifics (draw index, multiview, vector select, gather/compare/load variants, PBO
    storage, transform-feedback compute) and every node material class via `build()`
    (`g10_mat_*`, incl. batched/instanced meshes and clipping). Records add `transforms`
    for compute.
upstream/      probe_wgsl.mjs (upstream WGSL + GLSL generation in Node without a GPU),
               fn_ids.mjs (counts the `fn<id>` names upstream assigns at module load; the
               per-function table is tools/gen_fn_layout_names.mjs in the repo).
mock_gpu_body.js, mock_gpu.cjs   Recording mock WebGPU (generated by tools/gen_gpu_mock.mjs
               in the repo; also embedded in src/renderers/gpu/gpu_mock_gpu_test.mbt;
               `node tools/gen_gpu_mock.mjs --check` verifies all three are current).
               The mock-GPU harnesses (diff/core/g9, diff/addons/objects, ...) load it.
smoke_mock.mjs, smoke_upstream.mjs   Mock smoke tests; smoke_upstream renders a box with
               upstream WebGPURenderer on the mock (`--summary`: 94 calls; `--async`).
  - A4 (TSL display add-ons, src/addons/tsl): src/addons/tsl/a4_shader_diff_test.mbt (group
    `basic`) and a4_<group>_shader_diff_test.mbt (blur, ao, ssr, pass) against
    shader_diff/upstream_a4.mjs, which runs each group (shader_diff/a4/<group>.mjs) in a fresh
    child process (a4/child.mjs, with the `three/*` resolve hooks of a4/register_three.mjs),
    as run.mjs runs each MoonBit file in its own `moon test`. The group's add-on modules are
    imported first, as the MoonBit file calls their `load_*()`. A scenario flows the add-on
    node through WGSLNodeBuilder (+ declarations), then builds every internal material it set
    up with a full `build()`; `glsl: true` repeats it through GLSLNodeBuilder (`<name>_glsl`).
    `node shader_diff/run_a4.mjs [--group g] [--show] [name ...]` runs only these.
  - A5 (the other TSL add-ons: lighting, shadows, passes, temporal, utils):
    src/addons/tsl/a5_<group>_shader_diff_test.mbt (helpers in a5_harness_test.mbt) against
    shader_diff/upstream_a5.mjs, one child process per group (a5/child.mjs, a5/<group>.mjs,
    resolve hooks from a4/register_three.mjs). `node shader_diff/run_a5.mjs [--group g,h]
    [--show] [name ...]` runs only these.
  - A6 (WebGPU objects add-ons: SkyMesh, WaterMesh, Water2Mesh, LensflareMesh):
    src/addons/objects/a6_shader_diff_test.mbt against shader_diff/upstream_a6.mjs
    (a6/child.mjs with a6/register_three.mjs), WGSL and GLSL (`<name>_glsl`).
  - The TSL add-on children and the MoonBit A4/A5/A6 files create the recording mock
    WebGL 2 context from diff/core/webgl/harness/mock_gl.cjs (the src tests find it by
    walking up from the module root to `diff/`).

Bug injection for the shader scenarios lives with each group's tools (diff/addons/tsl/a4,
diff/addons/tsl/a5, diff/addons/objects); they patch src/ through diff/lib/inject.py and
rerun `node shader_diff/run.mjs <names>` here.
